В настоящий момент работа настроена на Yandex Object Storage.

Для работы из клиента достаточно FilesController.GetAll. Вернется список FileItem в формате Json.
Свойства FileItem:
    Url - ссылка на файл, доступная в интернете.
    Key - идентификатор файла вида top_level_prefix/subprefix/somefile.ext, где префиксы имитируют
          структуру каталогов внутри бакета (контейнера хранимых файлов).

Для работы в админке доступны функции загрузки на сервер (массивом байт), скачивания (массива байт) и удаления.

Максимальный размер данных в хранилище - 1 Гб. Необходимо подключение к интернету.
